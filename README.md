# -us-healthcare-analysis
Analysis of a 10,000-patient US hospital dataset — billing trends, admission patterns, and medication insights using Python and pandas.
Overview
Analyzed a hospital dataset of around 10,000 patients covering demographics, billing, insurance, and test results to find trends in healthcare costs and patient patterns.
What I Did
•  Cleaned and preprocessed the raw dataset using Python and pandas
•  Performed exploratory data analysis to understand distributions and relationships
•  Built visualizations to highlight key trends
•  Identified patterns in billing amounts, admission types, and medication usage
Tools Used
•  Python, pandas, NumPy
•  Matplotlib, Seaborn
•  Jupyter Notebook
How to Run
1.  Clone this repository
2.  Install dependencies: pip install pandas numpy matplotlib seaborn
3.  Open the notebook and run all cells
Key Findings
•  Billing amounts varied significantly by admission type and insurance provider
•  Medication patterns showed clear trends across patient demographics
